# Nusvara Menu

Halaman menu untuk pelanggan yang memindai QR di meja toko yang memakai Nusvara Cashier.

- Pelanggan melihat menu, memilih varian/tambahan, lalu mengirim pesanan.
- Pesanan masuk ke kasir dan menunggu kasir menerima atau menolak. Pembayaran di kasir.
- Halaman ini hanya berisi file statis tanpa data rahasia. Menu dibaca dari file publik yang diterbitkan kasir; harga selalu dihitung ulang di server.

Sumber halaman ada di repositori kasir (folder `menu-web/`). File di sini disalin dari sana.
